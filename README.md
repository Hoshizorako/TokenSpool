# TokenSpool

Transfers cryptocurrency transaction data from various exchanges to a single, unified platform for easy monitoring.

TokenSpool is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- Transfers cryptocurrency transaction data from
- various exchanges to a single,
- unified platform for easy monitoring

## Technology Stack

- python
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/TokenSpool.git`
2. `cd TokenSpool`
3. Install in editable mode: `pip install -e .`

## Configuration

TokenSpool is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
